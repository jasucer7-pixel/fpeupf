# Segunda Mente FPE

App de estudio para el grado en Filosofía, Política y Economía (UPF): organizarte, concentrarte y no agobiarte.

- **Hoy**: check-in de energía (baja / normal / alta) que limita cuántas cosas eliges, lo de hoy, lo que se acerca, minutos de foco y racha.
- **Foco**: temporizador por bloques (25/5, 50/10, 15/3, 10/2) ligado a asignatura y tarea, con aparcadero de distracciones.
- **Plan**: asignaturas, tareas, lecturas, entregas y exámenes ordenados por fecha; trocear tareas con IA.
- **Mente**: captura rápida (apuntes, ideas, dudas para clase, descarga mental) y chat con tu segunda mente.
- **Calma**: plan anti-agobio de 3 pasos, respiración guiada y el ejercicio de Epicteto de lo que depende de ti.

`src/segunda-mente.html` es la fuente (artefacto de Claude). `index.html` es la versión independiente: ábrela en el navegador o publícala con GitHub Pages; guarda los datos en el navegador.
